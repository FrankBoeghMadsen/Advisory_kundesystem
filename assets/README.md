# Eksisterende identitetsaktiv

`advisory-compass.png` er en uændret kopi af `logo-ikon-transparent.png` fra
ejerens `Grafik og designlinje`-mappe. Originalen er ikke ændret.
Kompakt kompasikon i sidepanelet ved programnavnet og som browserikon.

Farvegrundlag: Frank Bøgh Madsen Advisory Designmanual v1.2, 15. juli 2026,
afsnit 5 og 14: Authority Blue #000080, Signal Blue Light #CDEFF8,
Deep Graphite #1F2933, Soft Grey #E5E7EB, Warm Off-white #F7F5EF og White #FFFFFF.
Grøn og guld er valgfrie, sparsomme metode/accentfarver og er ikke tilføjet.
